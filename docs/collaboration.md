# 팀원 Codex 작업 방법

1. 팀 회의에서 확정된 Issue를 받아 담당 경로, 선행 Issue, 완료 조건을 확인한다.
2. Issue별 브랜치를 만들고 저장소에서 Codex를 연다. 루트 AGENTS.md, 담당 앱 AGENTS.md, 관련 API/디자인 부분을 읽도록 요청한다.
3. 수정 예상 경로와 검증 계획을 확인하고 작업한다. 공유 파일이나 계약 변경이 필요하면 영향과 필요한 결정을 Issue에 적어 팀장과 조정한다.
4. 구현 후 diff와 검증 결과를 확인하고 Issue를 연결한 PR을 올린다.

## Codex에 줄 시작 문장

> Issue #번호를 기준으로 작업해. 관련 지침과 계약 부분을 읽고, 담당 경로와 검증 계획을 먼저 알려줘. 공유 파일이나 계약 변경이 필요하면 영향과 선택지를 보고해. 완료 후 실행한 검사와 남은 작업을 정리해.

## Issue 업데이트

- 시작 · 담당 / 목표 / 수정 예상 경로 / 선행 조건 / 검증 계획
- 진행 · 완료한 단계 / 차단 원인과 재개 조건 / 필요한 결정
- 완료 · 변경 요약 / 검증 결과 / PR / 남은 작업과 후속 의존성

팀장은 주간 회의에서 확정 Issue, 담당, 마감, 완료 조건을 공유한다. 보드를 사용한다면 Todo → In Progress → In Review → Done을 기준으로 갱신하고, 차단 시 Blocked와 재개 조건을 기록한다.
